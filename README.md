# Ecommerce-Purchase-Intent-Classifier

## Problem Statement
To predict whether an online visitor will complete a purchase using machine learning classification models.


## Dataset Description
The Online Shoppers Purchasing Intention dataset contains 12,330 sessions with 18 behavioral and technical features collected from an e-commerce website.

## Observations


| Model | Observation |
|------|------------|
| Logistic Regression | Performs well due to linear separability |
| Decision Tree | Tends to overfit without pruning |
| KNN | Sensitive to feature scaling |
| Naive Bayes | Fast but assumes independence |
| Random Forest | Handles non-linearity effectively |
| XGBoost | Best overall performance |
